## Remaining

Measured on `origin/main` at commit `8bd6632`.

- The cell history is a screen, not a drawer: no focus trap, no `Escape` close, no focus restore to the originating cell, and no screen links to it yet (the route exists in `apps/web/src/router.ts`, and the screen asks for a cell when none is chosen). Consequently the keyboard traversal test of task 16 covers the arrows, Home/End, Page Up/Down and the live-region announcement, but not a wrap-around (the focus is clamped at the ends) and not a drawer.
- No `Enter` binding opens the history from a difference row, and the palette has no contrast test: the AA contrast is claimed in the CSS comments (`apps/web/src/styles.css`, `compare.css`) but never measured.
- The performance check of SUT-N-03 was not run in a browser: `e2e/smoke.spec.ts` covers the shell, the language switch, the navigation and the demo assets, and no 200,000-cell ChangeSet is scrolled under Playwright. Only `packages/ui/src/virtual-window.test.ts` asserts that a huge list is never rendered whole.
- The filter defaults to every nature, so the format changes are not hidden by default, and the summary counts are the engine's totals rather than the filtered ones.
- The virtual window handles the rows only; there is no column windowing.
- The analysis and the comparison still run on the main thread (no web worker), which is what SUT-N-03 asks for.
